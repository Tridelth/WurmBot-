WurmHelper
Attention!!

I personally used this mod only on servers where client modes were not prohibited. Obey the server rules and don't use this mod if autoclickers, macros or another automation tools were banned on the server

Usage:

type "info" in game console to see the list of available commands

What mod can do:

Automatic crafting
Automatic mining and smelting
Automatic forestry
Automatic foraging and botanizing
Some tools for automatic inventory items management
Automatic item improving
Another various things, making the gameplay easier
